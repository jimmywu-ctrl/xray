# 源码发布说明

## 版本来源

以本地当前部署版本 `20261103-controls-verified` 为来源，发布前核对 Electron 入口源码与已安装 app.asar 中入口一致。

源代码、界面资源、桌面图标和自动化测试均包含在仓库中。发布专用调整仅涉及：移除开发机路径、替换演示昵称、让测试入口使用本机 Node.js、增加 Node 24 版本要求与公开文档。未改变生产监控业务逻辑。

## 未包含的内容

- 微信数据库、解密密钥、账号目录和聊天记录。
- Telegram API 凭据、Bot Token、手机号与登录会话。
- AVE Cookie、浏览器登录态和 API 密钥。
- 真实群列表、个人备注、统计数据库、运行日志和诊断导出。
- 旧备份、验收截图、测试输出、本机绝对路径和安装包。

仓库为独立源码快照，不带本地历史。提交作者使用通用项目身份，不使用个人姓名或邮箱。GitHub 仓库归属、公开账号及推送平台活动由 GitHub 自身展示，源码脱敏不能隐藏这些平台信息。

## 验证边界

自动化测试验证本地逻辑；模拟适配器不代表真实第三方登录、微信版本兼容或真实群消息已端到端验证。本次发布不启动第二个生产监控实例、不修改本机账号配置。
